# Layouts — not yet

Cinder cannot load a custom Now Playing layout yet. The plan for how it will
([`docs/PLAN_now_playing_layouts.md`](https://github.com/superwilso/Cinder/blob/main/docs/PLAN_now_playing_layouts.md)
in the Cinder repository) shares them here, the same way as palettes: a text file per layout, checked
by CI with the player's own rules, and previewed with the player's own renderer.

Until then this folder is empty on purpose. Please don't send layouts yet: there is nothing to check them with.
